# Convite não oficial

Um convite especial para combinar um encontro com carinho, leveza e um pouco de humor.

## Sobre o projeto

Uma experiência interativa para escolher os detalhes de um encontro:

- Local preferido
- Data e horário
- Observações importantes
- Memes para deixar o convite mais divertido

Feito para transformar um simples convite em uma lembrança especial.
