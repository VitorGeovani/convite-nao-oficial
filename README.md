# Convite não oficial

Um convite especial para combinar um encontro com carinho, leveza e um pouco de humor.

## Como publicar

1. Abra as configurações do repositório no GitHub.
2. Acesse **Settings > Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde o GitHub disponibilizar o link.

Depois, é só compartilhar o endereço da página com a pessoa convidada. As escolhas feitas no convite são encaminhadas automaticamente para o responsável pelo projeto.
